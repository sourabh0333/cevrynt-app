# Cevrynt starter pack

1. Rename this folder to `cevrynt-app` (optional) and open it in Claude Code. The Next.js code will be created inside it.
2. This folder already contains:
   - `CLAUDE.md` — rules Claude Code reads automatically
   - `BUILD-PLAN.md` — the requests to give Claude Code, in order
   - `design/` — the final design of every page (reference only)
   - `public/brand/` — Cevrynt logos
3. Start with Step 1 in BUILD-PLAN.md. Paste one request at a time and check it before the next.
